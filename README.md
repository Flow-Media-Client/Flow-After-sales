## 📮 这里能解决什么

到 [Issues](../../issues/new/choose) 提交,会处理以下三类问题:

### 1. 激活码无法使用 / 验证失败
比如输入提示无效、过期、已被使用、网络异常等。

请在 issue 里附上:
- **订单号**(从购买页或邮件里找)
- **激活码**(可打码后几位,如 `TV-PSWD-VE8V-XXXX-XXXX`)
- App 内显示的**完整错误提示**或截图

### 2. 订单与支付问题
- 已付款但没收到激活码
- 重复扣款 / 退款申请
- 订单状态异常

请附上:
- **订单号**
- **支付方式与时间**
- 必要时附上支付凭证截图(可隐去敏感信息)

### 3. 重装 / 换机后授权恢复失败
正常情况下重装 App 会自动恢复授权。如果失败:

请附上:
- **订单号**或**激活码**
- **设备型号 + Android 版本**
- 是否更换过设备 / 重置过系统
- App 内 Restore 失败的提示截图

## ❓ 这里**不**处理什么

以下问题请走对应渠道,在这里提会被关闭并引导:

| 问题类型 | 应该去 |
|---------|--------|
| App 崩溃、播放异常、字幕/弹幕问题 | [Flow-release Issues](https://github.com/Flow-Media-Client/Flow-release/issues) |
| 功能建议、想法、求助 | [Flow-release Discussions](https://github.com/Flow-Media-Client/Flow-release/discussions) |
| 媒体服务器(Jellyfin / Emby)本身的问题 | 各自上游项目 |

## 🔒 隐私提示

- **不要**在 public issue 里贴**完整未打码**的激活码——任何人都能看到
- 订单号、邮箱可以贴,激活码请隐去后几位
- 如果涉及个人信息,可以在 issue 里说明,我们会引导走私下渠道处理

## ⏱ 响应时间

工作日通常 24 小时内回复,周末与节假日可能延迟。请耐心等待,**不要**重复开 issue。
